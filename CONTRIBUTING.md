# Contribuir a VUMARI STUDIOS

Las propuestas deben responder a una necesidad verificable del sitio y respetar
la separación entre la marca VUMARI STUDIOS y la autoría técnica individual.

## Flujo

1. Abre un issue o describe con claridad el problema que resolverá el cambio.
2. Crea una rama descriptiva, por ejemplo `feature/portfolio` o
   `fix/mobile-navigation`.
3. Mantén datos, estilos y comportamiento en sus módulos correspondientes.
4. Ejecuta `npm run check` antes de solicitar revisión.
5. Presenta el cambio con un commit claro y explica cómo fue verificado.

## Convenciones

- HTML semántico, CSS mobile-first y JavaScript ES Modules.
- Nombres de archivos web y slugs en `kebab-case`.
- Contenido real; no se aceptan clientes, cifras o resultados inventados.
- No se incorporan dependencias sin documentar necesidad, mantenimiento,
  licencia y peso.
- Las contribuciones no eliminan ni sustituyen la autoría original. Toda
  participación adicional se atribuye de forma precisa y verificable.

La aceptación de una contribución no implica cesión de la marca VUMARI STUDIOS
ni modifica automáticamente la licencia propietaria del repositorio.
